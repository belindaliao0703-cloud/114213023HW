AWS 作業報告

1. 何謂憑證、HTTPS、HTTP、Port

  • HTTP (HyperText Transfer Protocol)： 全名為HyperText Transfer Protocol，是全球資訊網（WWW）數據通訊的基礎，主要用於在瀏覽器和網站伺服器之間傳遞數據。因為http是以明文方式發送內容，任何人只要在中途攔截或監聽，像是在同一個公共 Wi-Fi 網路下，都能輕易讀取傳輸的報文。因此它非常不適合用來傳輸敏感資訊。因為安全度低，連線速度相對更快，資源消耗也相對更少。
  • HTTPS (HTTP Secure)： https全名為Hypertext Transfer Protocol Secure，是http的安全升級版。它在http的基礎上加入了 SSL/TLS 加密協定，用來加密數據封包並驗證網站伺服器的身分。 它的運作方式就像是要傳遞的訊息鎖進保險箱，，即使有人在半路攔截了這個保險箱，沒有鑰匙也不能看到裡面的內容。是搜尋引擎的優先收錄，連線速度較慢，資源消耗較高。
  • 憑證 (SSL/TLS Certificate)： 就像是數位世界裡的一張身分證或保證書。它主要包含了身分驗證及資料完整性兩大功能。它能讓在你看不到對發的前提下也能確認對方的身分，證明了這東西確實是由某個特定的人所發行，並且內容並沒有被任意修改或竄改。此外，它確保資料傳輸的安全，在真假難辨的網路環境中，為使用者們提供一層重要的安全保障，更是確保開發者權益的重要機制。
  • Port (連接埠)： Port 通常被稱為連接埠，它是一個基於軟體建立的虛擬端點。 當各種網路封包透過IP傳送到電腦時，它負責將這些雜亂無章的資料進行分類，並精準地派發給對應的應用程式或服務。

2. Inbound、Outbound 防火牆是什麼，怎麼設定

防火牆主要依據流量的方向來控管網路存取：

  • Inbound (入站防火牆)： 控制「外部流量進入內部網路/伺服器」的規則（例如：允許外部使用者連線至網站的 80/443 Port）。預設通常為完全阻擋。
  • Outbound (出站防火牆)： 控制「伺服器主動連線至外部網路」的規則（例如：伺服器下載套件更新）。預設通常為允許通過。

設定方式（以 AWS Security Group 為例）：

  1. 進入 AWS EC2 主控台，選擇目標執行個體 (Instance) 或安全性群組 (Security Group)。
  2. 點擊 Edit inbound rules (編輯入站規則) 或 Edit outbound rules (編輯出站規則)。
  3. 新增規則：指定 Type（如 HTTP/Custom TCP）、Port Range（如 80 或 22）與 Source（來源 IP，如 0.0.0.0/0 表示允許任何來源）。
  4. 儲存變更即可即時生效。

3. 什麼是 CIDR？

CIDR (Classless Inter-Domain Routing，無類別域間路由) 是一種靈活分配 IP 位址與進行網路路由的方法，解決了早期 IP 位址劃分浪費的問題。

語法表示： IP 位址 / 網路位元數

例如：192.168.1.0/24

  • /24 表示前 24 個位元為網路識別號，剩下 32 - 24 = 8 位元可用於分配主機。
  • 該區段總共有 2^8 = 256 個 IP 位址（範圍為 192.168.1.0 到 192.168.1.255）。
  • 在 AWS 中常用於規劃 VPC 與 Subnet 的網路規模（例如 10.0.0.0/16）。

4. 什麼是 DNS？什麼是 IP？什麼是域名？什麼是 URL？

  • IP (Internet Protocol Address)： 網路上設備的數位實體地址（如 140.128.x.x），電腦間透過 IP 互相連線。
  • 域名 (Domain Name)： 為了方便人類記憶而設計的文字名稱（如 www.ncnu.edu.tw），替代難記的數字 IP。
  • DNS (Domain Name System)： 網域名稱系統，就像是網路界的「電話簿」。負責將人類看得懂的域名解析翻譯成電腦看得懂的 IP 位址。
  • URL (Uniform Resource Locator)： 統一資源定位器，即完整的「網址」。用來精確指定網路上特定資源（網頁、圖片、檔案）的位置與存取方式。

5. URL 解析範例

解析目標：https://www.ncnu.edu.tw:1234/class/upload.php?file=abc[cite: 1]

URL 組成元素 對應內容 詳細說明
通訊協定 (Protocol) https:// 使用 SSL/TLS 加密傳輸的網頁通訊協定。
主機域名 (Domain) www.ncnu.edu.tw 伺服器的域名（國立暨南國際大學）。
連接埠 (Port) 1234 自訂的服務 Port 號（預設 HTTPS 為 443，此處指定使用 1234 連線）。
資源路徑 (Path) /class/upload.php 伺服器上的檔案路徑，指向 class 目錄下的 upload.php 程式。
查詢參數 (Query String) ?file=abc 帶給伺服器後端程式處理的參數，變數名稱為 file，其值為 abc。
